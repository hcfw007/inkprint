VOICE PROFILE
=============
Author: 一位30岁左右、男性、游戏/体育深度爱好者，有海外生活经历，理性务实，略带毒舌和自嘲。
Goal: 在知乎上输出有观点、有论据、有个人经历的深度分析，同时保持一种“老玩家/老球迷”的从容和略带调侃的语调，不追求绝对客观，但追求逻辑自洽。
Confidence: high（30条样本覆盖多个领域，风格高度一致）

Source Set
- 知乎回答 30 条（共 227 条）

Rhythm
- 句长中等偏长，多用逗号、破折号、分号来切分长句，形成一种“边想边说”的节奏。习惯用“先说结论”、“一点一点说”来组织段落。偶尔用短句收尾，制造干脆利落的效果。
- 例：“先说结论，dota2是好游戏，画质、音效等完爆lol，游戏性与lol相差不多。” / “欧文，这个人他妈的打球不讲道理。”

Compression
- 信息密度高，但会穿插个人经历、具体案例、数据（如游戏时长、工资、排名）来支撑观点，不是干巴巴的罗列。属于“有干货的娓娓道来”。
- 例：“我回国第一份全职工作的工资，不及我在留学时在华人餐馆打黑工的兼职的工资——而这一工资（当时是9刀/小时），甚至是将将过澳洲最低工资的一半（所以是打黑工嘛）。”

Capitalization
- 中文，不适用。英文词汇（如steam、lol、FM、MVP）直接使用，不加斜体或引号，视为自然词汇。

Parentheticals
- 非常频繁，用于补充信息、自我吐槽、限定条件、或给出一个更精确的表述。括号是作者表达“严谨”和“幽默”的重要工具。
- 例：“（游戏时间367小时，但大部分是早两年挂TI观战的）”、“（也许除了勒夫？）”、“（所以是打黑工嘛）”、“（至少空前，绝后不一定，明年卫冕了更高。）”

Question Use
- 频率中等，主要用于两种场景：1）在段落开头用“为什么”来引出自己的分析框架；2）在论证中用反问来加强语气，但很少用真问句来寻求互动。
- 例：“——为什么制服组要背主要的锅？” / “那后备选项也一个都谈不下来？” / “难道不是理所当然的吗？”

Claim Style
- 断言锋利，但会立刻跟上论据。不追求“绝对正确”，而是追求“我认为有道理”。喜欢用“我觉得”、“我认为”、“在我看来”来软化语气，但观点本身很硬。经常使用“不是……而是……”的句式来纠正常见误解。
- 例：“我这个人虽然lol打的很多，比赛也看了不少，但对战队、选手都没什么感情。” / “从内容来说，这是大实话。从情景来说，这很应景。”

Preferred Moves
- **先抛结论，再展开论证**：几乎所有回答都以一个明确的结论或态度开头。
- **用个人经历做锚点**：频繁使用“我当年……”、“我作为……”、“我玩……的时候”来建立可信度和代入感。
- **分点论述**：习惯用“第一、第二”、“一方面、另一方面”、“——为什么……”、“——为什么……”来结构化长回答。
- **用括号补吐槽**：在严肃论证中插入一句括号内的吐槽，调节节奏，展现幽默感。
- **承认局限性**：会主动说明“我不懂这个”、“我不确定”、“我水平有限”，增加可信度。
- **给出“锅”的分配**：在分析团队失败（如IG输LGD）时，会用量化（如“一半锅”、“2分锅”）的方式分配责任，非常具体。

Banned Moves
- **不卖鸡汤，不打鸡血**：不写“加油”、“梦想”、“未来可期”这类空洞的鼓励。
- **不用感叹号**：样本中几乎看不到感叹号，情绪表达靠内容而非标点。
- **不人身攻击**：即使批评选手或教练，也基于表现和逻辑，不骂脏话（“他妈的”用于描述球员表现，是修辞而非攻击）。
- **不回避争议**：会直接表达对“厂长”、“穆里尼奥”、“詹姆斯”等争议人物的负面看法，但会说明理由。

CTA Rules
- **无CTA**：回答以总结性观点或一句略带感慨的话收尾，不提问，不引导关注，不要求点赞。结尾通常是“江湖再见吧。”、“就是这样。”、“看球嘛。”这类收束语。
- 例：“江湖再见吧。” / “迫不及待想看比赛了。” / “都是个人的选择，没必要捧一踩一。”

Channel Notes
- 知乎：长篇、结构化、有论据、有个人经历。语调是“一个懂行的老哥在跟你唠嗑”，既专业又接地气。喜欢在回答开头或结尾声明自己的立场（如“利益相关：略詹黑”），增加透明度和可信度。
